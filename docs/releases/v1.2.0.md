This is the stable release of the upstream-following `main` line. The plugin
source matches ArduPilot commit
[`3e2f9253adc2d41e17b2f0fec74f4b2487c42fb0`](https://github.com/ArduPilot/plotjuggler-apbin-plugins/commit/3e2f9253adc2d41e17b2f0fec74f4b2487c42fb0).

## Changes since that upstream release

- Includes upstream fixes for per-load parser state, GPS/time synchronization,
  timestamp initialization and full-width parameter names.
- Includes upstream parameter/default labels, synchronized message timelines,
  optional RCOU/RCO2 servo-function labels and embedded field descriptions.
- Handles the legacy `QZ` and newer `QBBZ` MSG layouts using their FMT field names.
- Publishes three build-option combinations on both Windows and Linux. These
  combinations are separately checked against the upstream recorded BIN log;
  the parser source itself is unchanged from the recorded upstream checkpoint.
- Adds guarded upstream synchronization and auditable artifact promotion. No
  source translation or Chinese UI is added by this plugin release.

## Downloads and compatibility

Windows assets are x86-64 MSVC builds using Qt 5.15.2 and the PlotJuggler 3.9.2
DataLoader C++ interface. Linux assets are x86-64 builds in Ubuntu 22.04 using
its Qt 5 libraries and PlotJuggler 3.9.2. A compatible PlotJuggler/Qt runtime
must already be installed; these files are plugins, not a standalone viewer.

Choose exactly one variant for your OS:

- `DataAPBin_no_units.dll` / `libDataAPBin_no_units.so`: plain field names;
  `ADD_UNITS=OFF`, `ADD_RCOU_FUNCTION_LABELS=OFF`.
- `DataAPBin_with_units.dll` / `libDataAPBin_with_units.so`: units in field
  labels; `ADD_UNITS=ON`, `ADD_RCOU_FUNCTION_LABELS=OFF`.
- `DataAPBin_with_units_rcou.dll` / `libDataAPBin_with_units_rcou.so`: units and
  configured RCOU/RCO2 function labels; both options `ON`.

Only PlotJuggler 3.9.2 is the tested binary-host boundary for these downloads.
Compatibility with other PlotJuggler 3 versions, including 3.18, is not claimed.
They cannot load through the PlotJuggler 4 SDK ABI. macOS, ARM, ROS packages and
other Qt/compiler combinations are not distributed or verified here.

## Installation

1. Verify the chosen file against `SHA256SUMS`.
2. Close PlotJuggler and remove an older APBIN plugin from the plugin directory
   to avoid loading two copies. Keep only one of the variants above.
3. Copy the chosen library to the directory configured in PlotJuggler's plugin
   search paths. The descriptive download filename may be retained.
4. Start the compatible PlotJuggler host, confirm the APBIN loader is listed,
   and open an ArduPilot DataFlash `.BIN` log.

## Validation and limits

All six installed shared libraries are dynamically loaded by the native Qt
DataLoader harness and parse `tests/logs/00000001.BIN`; unit and RCOU labels are
asserted according to each build's actual options. Test fixture SHA-256:
`28dcbac522ceb75eee10f6af37b0d6e342c1dc79e2be1a9f766fe18a14336766`.
This covers plugin discovery, loading and recorded-data decoding, not a full
interactive GUI review or every possible ArduPilot message schema.

The upstream parser's behavior and limits remain applicable. Large logs require
sufficient memory, and recorded logs should come from trusted sources. The
SDK4 branch's independent hardening is not claimed as a change to this main
release.
