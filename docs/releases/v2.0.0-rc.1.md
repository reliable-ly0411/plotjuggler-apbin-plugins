# ArduPilot BIN v2.0.0-rc.1 — PlotJuggler 4 SDK

This is an independent **prerelease** for the `plotjuggler-4.x-sdk` line. Its
embedded plugin manifest identifies `2.0.0-rc.1`. The major-version change
marks the incompatible move from the PlotJuggler 3 Qt/C++ DataLoader interface
to the PlotJuggler 4 native SDK C ABI. This prerelease does not replace the
stable main-line release or its Latest designation.

The original parser baseline is ArduPilot commit
[`3e2f9253adc2d41e17b2f0fec74f4b2487c42fb0`](https://github.com/ArduPilot/plotjuggler-apbin-plugins/commit/3e2f9253adc2d41e17b2f0fec74f4b2487c42fb0).
ArduPilot has no corresponding SDK4 release or SDK4 release notes. The latest
original APBIN release is v1.1.0; its full notes are retained below as provenance,
not as a claim that upstream published or certified this adapter.

## SDK4 adaptation

- Provides a Qt-free C++20 DataFlash decoder and a separately loaded native
  `ardupilot_source_plugin` shared library. It is not linked into the viewer.
- Retains numeric fields, sensor instances, UNIT/MULT scaling, legacy/current
  PARM, both MSG layouts, parameter/default labels and message timelines.
- Preserves exact integer-microsecond timestamps until checked conversion to
  SDK nanoseconds; valid GPS samples synchronize the full log.
- Adds bounded FMT/FMTU handling, per-file state isolation, schema/type and
  timestamp checks, safe unaligned decoding and visible truncated-tail warnings.
- Supports UTF-8/Chinese paths through the native filesystem boundary, including
  Windows; stop and host-write errors are covered by the shared-library tests.
- Retains upstream description XML as dataset metadata. The adapter is not a
  Chinese localization of the upstream Qt plugin.

## Downloads and compatibility

Both packages require **plotjuggler_sdk 0.34.1**, pinned at
[`4d59e7de81455afe73a77051075e8fb4b9f6b0fd`](https://github.com/PlotJuggler/plotjuggler_sdk/tree/4d59e7de81455afe73a77051075e8fb4b9f6b0fd),
with boot ABI 5 and data-source protocol 4.

- `ardupilot_source_plugin-v2.0.0-rc.1-sdk0.34.1-linux-ubuntu22.04-x86_64.zip`:
  native GCC 12 x86-64 shared library built on Ubuntu 22.04.
- `ardupilot_source_plugin-v2.0.0-rc.1-sdk0.34.1-windows-x86_64.zip`:
  native MSVC x86-64 DLL built on Windows Server 2022.

Each archive includes the shared library, its inspection manifest, installation
README, exact source attribution and required licenses. A compatible native
PlotJuggler 4 host and its platform runtime must already be installed. The
Windows build uses the MSVC runtime; Linux uses the standard C/C++ runtime.
The host's SDK commit/ABI must match the boundary above. Compatibility with
other SDK releases or all future PlotJuggler 4 builds is not promised.
PlotJuggler 3, macOS, ARM, static embedding and WebAssembly are not supported
by these packages.

## Installation

1. Verify the selected ZIP against `SHA256SUMS`, then extract it fully.
2. Close the host. Keep the plugin library and `.pjmanifest.json` sidecar
   together, with the included licenses/source attribution retained.
3. Put that directory in the host's configured plugin path or launch the host
   with `--plugin-dir <directory>`. Do not put this DLL/SO in a PlotJuggler 3
   plugin directory, and avoid duplicate copies of `ardupilot-dataflash`.
4. Confirm **ArduPilot BIN** is listed, then open a `.BIN` file. Headless source
   configuration is `{"filepath":"/path/to/log.BIN"}`.

## Validation and known limits

Both platforms run parser fixtures and dynamic SDK C-ABI tests, including the
original recorded BIN (SHA-256
`28dcbac522ceb75eee10f6af37b0d6e342c1dc79e2be1a9f766fe18a14336766`),
Unicode paths, truncation, malformed schemas, stop, retry/state isolation and
host errors. The final ZIP is unpacked and its shipped shared library is tested
again before upload. Linux parser fixtures additionally run with ASan/UBSan.
These tests use the actual SDK host boundary; they are not a full interactive
GUI certification or validation against every aircraft/firmware log.

- The original fixed 18-second GPS/UTC offset assumes logs from 2017 onward.
- Scalar curve-hover tooltip parity is not implemented because this SDK has no
  equivalent scalar tooltip writer; descriptions are retained in dataset metadata.
- Array payloads, ISBD/ISBH and free-text fields other than MSG/PARM are not
  plotted. Optional RCOU function-name labels are not enabled.
- Large files and decoded samples are held in memory. Numeric values remain
  doubles, while timestamps are integral.
- A truncated tail retains earlier complete samples with a warning; invalid
  schemas fail before host data creation. Stop retains data for the host's
  Keep/Discard decision.

See the source-tag `sdk4/docs/PORT_AUDIT.md` for the feature boundary and
`sdk4/UPSTREAM.md` for provenance.
